# NotebookLM RAG Brain & Artifacts

**Objective:** Leverage Google NotebookLM via MCP as a memory bank, deep researcher, and multimedia generator.

## Core Directives
1. **Token Preservation:** Upload massive documents/manuals to NotebookLM instead of chat context.
2. **Source Grounding:** Ensure all output relies strictly on uploaded notebook sources.
3. **Authentication:** Prompt user to refresh connection in browser if MCP is inactive.

## Execution Modules
### Module 1: Project Brain
Create persistent RAG storage for rules, guidelines, and historical context.

### Module 2: Senior Prompt Engineer
Upload technical PDFs -> Configure custom instructions -> Query for exact JSON/API syntax.

### Module 3: Deep Research
Use "Discover Sources" to pull web data and synthesize into structured tables for the build.

### Module 4: Artifact Generation
- **Slide Decks:** Generate Google Slides/PowerPoint from source material.
- **Video Overviews:** Narrated walkthroughs based on docs.
- **Other:** Infographics, study guides, and audio overviews.

## Implementation Protocol
When asked to "Use the NotebookLM Skill":
1. Assess need (Memory, API Help, Research, Artifacts).
2. Initialize notebook and request source uploads.
3. Execute MCP query (request structured data).
4. Integrate output into active codebase.
