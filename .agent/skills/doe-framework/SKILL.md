# Project Initialization & D.O.E. Framework

**Objective:** Establish workspace architecture, enforce security, and structure iterative building.

## Core Directives
1. **Master Brain:** Never code without a central `instructions.md` or `gemini.md`.
2. **Security by Default:** Always use `.env`/`.gitignore` for secrets.
3. **Iterative Loop (D.O.E.):** Directive (SOP) -> Observation (Logs) -> Experiment (Fix).

## Execution Modules
### Module 1: Scaffolding
Create `instructions/`, `execution/`, and `temp/` folders. Establish the central brain document.

### Module 2: D.O.E. (Directive/Observation/Experiment)
Write SOP -> Run Code -> Observe Terminal -> Autonomous Fix.

### Module 3: Security
Initialize `.env` for API keys and `.gitignore` to prevent exposure.

### Module 4: Brand Alignment
Analyze references -> Extract Hex/Typography/Mood -> Save to `brand_guidelines.md`.

## Implementation Protocol
When asked to "Initialize this project using the D.O.E. Skill":
1. Scaffold folders.
2. Secure `.env` and `.gitignore`.
3. Establish the Brain (`gemini.md`).
4. Generate `brand_guidelines.md` from references.
5. Return summary checklist.
