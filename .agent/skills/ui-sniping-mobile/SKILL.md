# Advanced UI Sniping & Mobile Deployment

**Objective:** Rapidly clone, build, and deploy stunning 3D web applications and native mobile applications using visual references, Google Stitch, and Flutter.

## Core Directives
1. **Visual Accuracy:** Extract brand guidelines, typography, layout, and CSS animations from screenshots/URLs.
2. **MCP Verification:** Ensure Stitch MCP, Stitch Loop Skill, and Flutter/Dart MCP are enabled.
3. **Image Hosting:** Use online image URLs (e.g., Imgur) for static assets.

## Execution Modules
### Module 1: UI Sniping
Analyze reference URLs or screenshots to replicate layout and animations in React or Vanilla.js.

### Module 2: 3D Spline Integration
When provided with a `prod.spline` URL, integrate the interactive 3D asset into the application background.

### Module 3: Stitch-to-Flutter Pipeline
1. **Design via Stitch:** Generate multi-screen UI.
2. **Stitch Loop:** Logically connect screens.
3. **Flutter MCP:** Convert design to a working mobile app.
4. **Package:** Run Pixel emulator and generate `.apk`.

### Module 4: Cloud Deployment
- **Static:** Deploy via Netlify CLI.
- **Dynamic:** Push to GitHub and connect to Vercel/Netlify.

## Implementation Protocol
When asked to "Initialize Skill 2 for this build":
1. Determine if building Web or Mobile.
2. Gather screenshots, Spline URLs, or API keys.
3. Build scaffold and interface.
4. Deploy/Package.
